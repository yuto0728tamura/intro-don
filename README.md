# 🎵 イントロどん！（早押し＆スコア管理Webアプリ）

30人規模のイベントやパーティで使える、リアルタイム早押しイントロドンWebアプリです。  
ホストPCで音楽を再生し、参加者は各自のスマートフォンから早押しボタンを押して回答権を競います。

---

## 🚀 参加用URL / QRコード

* **アプリURL**: `https://<あなたのGitHubユーザー名>.github.io/<リポジトリ名>/`
* **参加方法**: 上記URLへアクセスするか、URLを変換したQRコードをスマホのカメラで読み取ってアクセスしてください。

---

## ✨ 主な機能

### 📱 プレイヤー画面（スマートフォン）
* **簡単エントリー**: ニックネームを入力するだけで即座に参加可能。
* **リアルタイム早押しボタン**: ホストが早押しを解禁するとボタンが有効化。
* **排他ロック制御**: 一番最初に押したプレイヤーのみが回答権を獲得し、他のプレイヤーの画面には誰が押したかが即座に表示されます。

### 💻 ホスト画面（PC / プロジェクター投影用）
* **早押し判定表示**: 誰が一番早くボタンを押したかを大画面でリアルタイム表示。
* **ワンタップ判定・採点**: 「正解（+1pt）」「不正解」「早押し解禁（リセット）」をコントロール。
* **リアルタイムスコアボード**: 参加者全員の現在の獲得ポイントを自動で集計・一覧表示。

## 🛠 使用技術（動作仕組み）

* **フロントエンド**: HTML5 / CSS3 / JavaScript (Vanilla JS)
* **バックエンド / リアルタイム通信**: [Firebase Realtime Database](https://firebase.google.com/)
* **ホスティング**: GitHub Pages

## 📖 使い方（当日の流れ）

1. **ホストの準備**
   * PCでアプリURLを開き、「ホスト（管理画面）」を選択します。
   * PCからBGM（YouTubeやSpotify等）を流せるスピーカーを接続します。
2. **プレイヤーの参加**
   * 参加者は各自のスマホでURL（またはQRコード）を開き、「プレイヤー（スマホ）」を選択して名前を入力します。
3. **ゲームスタート**
   * ホストが曲を流し、ホスト画面の **「早押し解禁」** ボタンを押します。
   * プレイヤー画面の「押す！」ボタンが有効化され、最速で押した人の名前がホスト画面に表示されます。
   * ホストは回答を聞いて **「正解 (+1pt)」** または **「不正解」** を判定します。
